# Эмулятор оболочки ОС (Вариант 16)

## 1. Общее описание

Эмулятор командной строки UNIX-подобной ОС, реализованный на языке Java.
Этап 1:с командами-заглушками `ls`, `cd`
и командой выхода `exit`.

## 2. Функции и настройки

### Реализованные команды:
- `ls [аргументы]` — заглушка, выводит имя команды и её аргументы;
- `cd [аргументы]` — заглушка, выводит имя команды и её аргументы;
- `exit` — выход из эмулятора.

### Особенности:
- Приглашение к вводу формируется из реальных данных ОС:
  `username@hostname:~$`;
- Раскрытие переменных окружения реальной ОС: `$USERPROFILE` и т.д.;
- Обработка ошибок: неизвестная команда, пустой ввод.

## 3. Сборка и запуск

### Сборка:
```
javac src/ShellEmulator.java
```

### Запуск:
```
java -cp src ShellEmulator
```

### Запуск через скрипт:
```
run.bat
```

## 4. Примеры использования

```
ivan@laptop:~$ ls -la /home
Выполнена команда-заглушка: ls
Аргументы: [-la, /home]
ivan@laptop:~$ cd Documents
Выполнена команда-заглушка: cd
Аргументы: [Documents]
ivan@laptop:~$ ls $HOME
Выполнена команда-заглушка: ls
Аргументы: [/home/ivan]
ivan@laptop:~$ qwer
Ошибка: команда 'qwer' не найдена.
ivan@laptop:~$ exit
Выход из эмулятора
```
