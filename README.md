# Эмулятор оболочки ОС (Вариант №16)

## Общее описание

Эмулятор командной строки UNIX-подобной ОС, реализованный на языке Java.
Приложение работает в режиме REPL (Read-Eval-Print Loop) и имитирует
диалог с пользователем через консольный интерфейс (CLI).

На текущем этапе (Этап 2 «Конфигурация») реализованы:

- Разбор параметров командной строки:
    - `--vfs <путь>` — путь к физическому расположению VFS;
    - `--script <путь>` — путь к стартовому скрипту;
    - `--debug` — включение отладочного вывода параметров при запуске.
- Отладочный вывод всех заданных параметров при старте эмулятора.
- Выполнение стартового скрипта с отображением ввода и вывода,
  имитирующего диалог с пользователем.
- Обработка ошибок:
    - неизвестный параметр командной строки;
    - отсутствие значения после `--vfs` или `--script`;
    - отсутствие файла стартового скрипта;
    - ошибка чтения стартового скрипта;
    - ошибка выполнения команды внутри скрипта (строка пропускается
      с сообщением об ошибке).
- Поддержка комментариев в стартовом скрипте (строки, начинающиеся с `#`).
- Раскрытие переменных окружения реальной ОС (например, `$HOME`) в
  аргументах команд.
- Команды-заглушки: `ls`, `cd`.
- Команда `exit` для выхода из эмулятора.

## Описание всех функций и настроек

### Параметры командной строки

| Параметр   | Описание                                              | Обязательный |
|------------|-------------------------------------------------------|--------------|
| `--vfs`    | Путь к физическому расположению VFS                   | Нет          |
| `--script` | Путь к стартовому скрипту для выполнения команд       | Нет          |
| `--debug`  | Включить отладочный вывод параметров при запуске      | Нет          |

Если параметр `--script` не указан — запускается интерактивный режим REPL.
Если указан `--script` — эмулятор выполняет команды из файла и завершается.

### Основные методы класса `Main`

| Метод                          | Назначение                                                              |
|--------------------------------|-------------------------------------------------------------------------|
| `main(String[] args)`          | Точка входа. Разбирает аргументы, запускает скрипт или REPL.            |
| `parseArgs(String[] args)`     | Разбирает параметры командной строки. Возвращает `false` при ошибке.    |
| `printDebugInfo()`             | Выводит отладочную информацию о заданных параметрах.                    |
| `runRepl()`                    | Запускает интерактивный цикл чтения команд.                             |
| `runScript(String path)`       | Выполняет команды из стартового скрипта.                                |
| `handleInput(String input)`    | Обрабатывает одну строку ввода в режиме REPL.                           |
| `executeCommand(String input)` | Разбирает строку на команду и аргументы, выполняет команду.             |
| `printStub(String, String[])`  | Выводит имя команды-заглушки и её аргументы.                            |
| `getPrompt()`                  | Формирует приглашение к вводу в формате `user@host:~$ `.                |
| `tokenize(String input)`       | Разбивает ввод на токены по пробелам.                                   |
| `expandVariables(String input)`| Раскрывает переменные окружения вида `$VAR` в строке.                   |

### Поддерживаемые команды

| Команда | Описание                                                        |
|---------|-----------------------------------------------------------------|
| `ls`    | Заглушка: выводит имя команды и переданные аргументы.           |
| `cd`    | Заглушка: принимает не более одного аргумента.                  |
| `exit`  | Завершает работу эмулятора. Не принимает аргументов.            |

### Формат стартового скрипта

- Одна команда на строку.
- Пустые строки игнорируются.
- Строки, начинающиеся с `#`, являются комментариями и игнорируются.
- При выполнении скрипта на экран выводится как ввод (с приглашением),
  так и результат выполнения команды.
- Если команда завершилась ошибкой, выводится сообщение об ошибке,
  и выполнение скрипта продолжается со следующей строки.
